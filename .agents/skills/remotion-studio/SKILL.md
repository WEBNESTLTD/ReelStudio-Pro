# Remotion Studio Guide

## Launching Remotion Studio
```bash
cd video-editor
npm start
# or
npx remotion studio src/index.ts
```

## Features
- Real-time frame scrubber and playback.
- Dynamic props editing panel.
- Composition switcher (Reel, Landscape, Square).
- Render progress visualization.
- Audio playback and waveform visualization.
